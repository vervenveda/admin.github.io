RouteKeeper™ — Private Infrastructure Console

RouteKeeper™ is the administrator-only registry and route-audit workspace for the Verve N Veda and ProReSources infrastructure.

Intended placement

Keep RouteKeeper local or inside a genuinely private administrative repository. Do not add RouteKeeper to the public ProReSources application directory.

Static HTML on GitHub Pages cannot provide server-side authentication. RouteKeeper therefore includes optional local AES-GCM workspace encryption, but the HTML application itself must still be treated as an administrative file.
